# Aufgaben verstehen

Aufgaben sind die zentralen Elemente in ChronoScope. Sie beschreiben Arbeit, die erledigt werden soll, und liefern dem Planungsalgorithmus die Informationen, die er für eine sinnvolle Einplanung braucht.

## Wichtige Angaben

| Angabe | Bedeutung |
| --- | --- |
| Titel | Kurzer Name der Aufgabe |
| Beschreibung | Zusätzliche Details für dich oder dein Team |
| Dauer | Geschätzter Arbeitsaufwand |
| Deadline | Zeitpunkt, bis zu dem die Aufgabe erledigt sein soll |
| Priorität | Wichtigkeit im Vergleich zu anderen Aufgaben |
| Abhängigkeiten | Aufgaben, die vorher erledigt sein müssen |
| Kognitive Last | Einschätzung, wie anstrengend die Aufgabe ist |

## Dynamische Aufgaben

Dynamische Aufgaben werden automatisch in freie Arbeitszeiten eingeplant. Sie eignen sich für Arbeit, die flexibel verschoben werden darf.

## Feste Termine und Blocker

Feste Termine haben eine konkrete Start- und Endzeit. Blocker markieren Zeiten, in denen ChronoScope keine Aufgaben einplanen soll.
