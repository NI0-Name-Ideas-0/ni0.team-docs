# Aufgaben verstehen

Aufgaben sind die zentralen Elemente in ChronoScope. Sie beschreiben Arbeit, die erledigt werden soll, und liefern dem Planungsalgorithmus die Informationen, die er fuer eine sinnvolle Einplanung braucht.

## Wichtige Angaben

| Angabe | Bedeutung |
| --- | --- |
| Titel | Kurzer Name der Aufgabe |
| Beschreibung | Zusaetzliche Details fuer dich oder dein Team |
| Dauer | Geschaetzter Arbeitsaufwand |
| Deadline | Zeitpunkt, bis zu dem die Aufgabe erledigt sein soll |
| Prioritaet | Wichtigkeit im Vergleich zu anderen Aufgaben |
| Abhaengigkeiten | Aufgaben, die vorher erledigt sein muessen |
| Kognitive Last | Einschaetzung, wie anstrengend die Aufgabe ist |

## Dynamische Aufgaben

Dynamische Aufgaben werden automatisch in freie Arbeitszeiten eingeplant. Sie eignen sich fuer Arbeit, die flexibel verschoben werden darf.

## Feste Termine und Blocker

Feste Termine haben eine konkrete Start- und Endzeit. Blocker markieren Zeiten, in denen ChronoScope keine Aufgaben einplanen soll.
