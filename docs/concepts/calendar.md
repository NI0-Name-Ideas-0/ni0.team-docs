# Kalender verstehen

Der Kalender zeigt, wann Aufgaben, Termine und Blocker geplant sind. Er ist die zentrale Ansicht, um den automatisch erzeugten Arbeitsplan zu pruefen und anzupassen.

## Typische Elemente

| Element | Zweck |
| --- | --- |
| Aufgabe | Automatisch oder manuell eingeplante Arbeit |
| Termin | Fester Zeitraum, der zur Arbeitsbelastung gehoert |
| Blocker | Nicht verfuegbare Zeit, zum Beispiel Pause oder privater Termin |
| Arbeitszeit | Zeitfenster, in dem Aufgaben eingeplant werden duerfen |
